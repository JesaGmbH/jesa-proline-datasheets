# JESA ProLine ASA-CF

ASA-basiertes Filament mit Carbonfaser-Verstärkung. Steif, maßhaltig und **UV- sowie wetterbeständig** — das richtige Material, wenn dein Teil draußen bestehen muss: Gartenhalterungen, Outdoor-Gehäuse, Fahrzeugteile, alles was Sonne, Regen und Temperaturwechsel abkriegt.

## Kennwerte im Überblick

| Eigenschaft | Wert | Prüfnorm |
|---|---|---|
| Zugfestigkeit (X-Y) | 39–42 MPa | ISO 527 |
| Biegefestigkeit (X-Y) | 80–82.5 MPa | ISO 178 |
| Schlagzähigkeit (X-Y) | 10.5–12 kJ/m² | ISO 180 |
| HDT @ 0.455 MPa | 88 °C | ISO 75 |
| Dauergebrauchstemperatur | 85 °C | IEC 60216 |
| Feuchtigkeitsaufnahme (24 h) | < 0.5 % | ISO 62 |
| Dichte | 1.09–1.10 g/cm³ | ISO 1183 |

## Vor dem Druck

- **Vortrocknen:** 80 °C, mindestens 5 h
- **Nach dem Druck (optional):** Tempern bei 80–100 °C, 1–3 h erhöht die Festigkeit spürbar
- **Düse:** gehärteter Stahl (Carbonfaser verschleißt Messing-Düsen)
- **Drucktemperatur:** 290–310 °C — höhere Werte als Standard-ASA
- **Kühlung:** Bauteillüfter nur auf 0–20 %, um Schichthaftung nicht zu schwächen

Vollständige Druckparameter stehen im Datenblatt.
