# JESA ProLine ABS

Zähes, schlagfestes ABS-Filament für funktionale Teile. Der klassische Einstieg, wenn PLA nicht mehr reicht — einfach zu drucken auf jedem gängigen FDM-Drucker, ohne Spezial-Düse, ohne Heizkammer.

## Kennwerte im Überblick

| Eigenschaft | Wert | Prüfnorm |
|---|---|---|
| Zugfestigkeit (X-Y) | 35–40 MPa | ISO 527 |
| Bruchdehnung (X-Y) | 12–17 % | ISO 527 |
| Biegefestigkeit (X-Y) | 65–70 MPa | ISO 178 |
| Schlagzähigkeit (X-Y) | 7–10.5 kJ/m² | ISO 180 |
| HDT @ 0.455 MPa | 88 °C | ISO 75 |
| Dichte | 1.04–1.06 g/cm³ | ISO 1183 |

Vollständige mechanische und thermische Werte sowie Prüfspezimen: siehe Datenblatt.

## Vor dem Druck

- **Vortrocknen:** 80 °C, mindestens 5 h (empfohlen bei längerer Lagerung)
- **Düse:** Messing reicht — keine gehärtete Düse nötig
- **Druckraum:** Raumtemperatur bis ~40 °C ausreichend, keine Heizkammer erforderlich

Vollständige Druckparameter (Drucktemperatur, Bettmaterial, Retraction) stehen im Datenblatt.
