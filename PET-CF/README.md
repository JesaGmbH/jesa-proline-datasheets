# JESA ProLine PET-CF

PET-basiertes 3D-Druck-Filament mit 10 % Carbonfaser-Verstärkung. Hohe Steifigkeit, geringer Verzug, **Dauergebrauchstemperatur bis 120 °C**. Druckbar auf FDM-Druckern ohne beheizte Kammer.

|---|---|---|

| Dauergebrauchstemperatur | 120 °C | IEC 60216 |
| Feuchtigkeitsaufnahme (24 h) | < 0.3 % | ISO 62 |
| Dichte | 1.30–1.31 g/cm³ | ISO 1183 |

## Vor dem Druck

PET-CF zieht Feuchtigkeit aus der Luft. Feuchtes Filament = Blasen, schwache Schichthaftung, sprödes Teil.

- **Vortrocknen:** 90–100 °C, mindestens 12 h
- **Düse:** gehärteter Stahl (Carbonfaser verschleißt Messing)
- **Tempern (optional):** 80-100 °C, 8 h nach dem Druck erhöht Festigkeit spürbar
